How it works

Three deliberate steps.

  1. 01

    Capture

    Type your reasoning, or use voice guidance when it helps.

  2. 02

    Review

    Check the exact proposed answer. Confirmation never writes by itself.

  3. 03

    Write

    Use the separate destination-specific action only when you are ready.

Confirmed, not written

Confirmation holds the answer still. You decide what happens next.

Change the answer and confirm again, write it to a safe response area, or place it in the export side panel when the page is uncertain.

Safety and access

The page stays safe. Voice stays optional.

Placement follows evidence

A verified response area can receive a confirmed answer. Uncertain placement uses the export side panel instead of guessing.

Typing works throughout

Microphone access is never required. Keyboard focus, typed answers, reduced motion, and document controls stay available.

Original pages are preserved

Drafts and confirmation do not alter the PDF. Only the separate write action authorizes an answer for export.

FAQ

A few useful details.

Does Claros grade the answer?

No. Claros helps the student shape and review an answer. It does not present AI correctness grading.

Which PDFs work best?

Worksheets with selectable text and clearly numbered tasks work best. Image-only scans may need OCR first.

When does the microphone turn on?

Only after the student chooses voice guidance and grants browser permission. Typed answers remain available.

Where are worksheets stored?

Uploaded PDFs and session state use the configured worksheet storage. Claros does not promise automatic timed deletion.
