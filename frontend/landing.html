A deliberate sequence

Every answer has two intentional moments.

Claros helps students work through one supported task at a time. It never treats a draft as permission to change the PDF.

  1. Open

    Choose a worksheet

    Claros identifies supported student tasks and shows the document first.

  2. Review

    Make the answer yours

    Type, or use voice guidance. Edit or reject the proposal before confirmation.

  3. Write

    Choose the destination

    A confirmed answer still waits for an explicit write action. Unsafe layouts route to the side panel.

  4. Export

    Take the completed PDF

    Export only after the answers you intended have been written.

Safe placement

Claros does not guess where an answer belongs.

When a worksheet has a safe answer line, the student can write there. When placement is uncertain, the original page stays untouched and the answer is added to a clearly labeled export side panel.

Common questions

What to expect from Claros

Does Claros give students answers?

No. Claros is prompted to guide with questions and hints. The student states, confirms, and deliberately writes the final answer.

Which PDFs work best?

Worksheets with selectable text and clearly numbered questions work best. Image-only scans may need OCR first.

When does the microphone turn on?

Only after the student starts voice guidance and grants browser permission. Typed answers remain available.

Where are worksheets stored?

Uploaded PDFs and session state use the configured worksheet storage so a session can restore and export.
