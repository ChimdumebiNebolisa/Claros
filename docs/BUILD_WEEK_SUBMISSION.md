# Claros Build Week submission framing

Claros is optimized for one demonstrable worksheet flow, not arbitrary PDFs.
The demo has a deterministic synthetic worksheet, closed-world task data, safe
physical response regions, and an intentionally uncertain drawing task that
uses the side panel.

The broader AI-adjudicated silver benchmark infrastructure remains in the
repository but is incomplete. Provider quota prevented its remaining
adjudication; it is not evidence of general agreement or broad support.

The demo replay is deterministic and does not make a fresh provider call.
Live compiler mode remains separate and requires a configured, funded OpenAI
credential. No answer is written without explicit student confirmation and a
server-issued, single-use authorization token.
