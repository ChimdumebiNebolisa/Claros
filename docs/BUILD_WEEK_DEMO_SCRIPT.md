does not claim broad PDF support.

1. Upload `demo/hero_worksheet.pdf` in replay mode.
2. Point out the compound parent and its `a` and `b` subparts.
3. Select subpart `a`; use the typed conversation path to enter a student
   answer.
4. Review, edit if needed, and explicitly confirm the exact candidate.
5. Show the answer written only to the validated answer line.
6. Select the drawing activity and show automatic side-panel routing.
7. Export the completed PDF.

Use the honest closing statement: GPT-5.6 can select document semantics in
live mode; deterministic code owns permissions, geometry, confirmation, and
document modification. The supplied demo replays a synthetic fixture while
