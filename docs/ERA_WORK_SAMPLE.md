# Claros work sample

The work sample is a full worksheet interaction: upload a fixed synthetic
hero PDF, display a structured task graph, guide a typed response, require
confirmation, safely write the confirmed response, route uncertain placement
to a side panel, and export the original worksheet with the completed work.

It demonstrates a strict division of responsibility: semantic selections are
closed-world data; deterministic code validates IDs and placement, protects
assignment access, controls the write token, and changes the PDF. The demo
does not claim that its fixture proves support for arbitrary document layouts.
