# Vendored Noto Sans

Claros embeds the static Noto Sans Regular and Bold TrueType fonts in generated
answer overlays and attached answer pages. The files are from the official
archived `notofonts/noto-fonts` repository, `main` branch:

- `hinted/ttf/NotoSans/NotoSans-Regular.ttf`
- `hinted/ttf/NotoSans/NotoSans-Bold.ttf`
- root `LICENSE`, stored here as `OFL.txt`
